# Staff Role Matrix V1

## 轉崗原則
先盤點現有美女顧問團角色，再依能力轉入製片公司職位。不得只看舊職稱；以實際產出能力與流水線缺口為準。每位員工只設一個主責 Skill，可有 1–2 個輔助能力，但不得越權取代其他專業。

## 必備職位
| 部門 | 主責 Skill | 核心產出 |
|---|---|---|
| 企劃 | Planning Skill | 題材、受眾、切角、平台假設、價值主張 |
| 編劇 | Screenwriter Skill | Hook、故事、台詞、轉折、高潮、CTA |
| 導演 | Director Skill | 導演意圖、分鏡、表演調度、節奏、視覺高潮 |
| 攝影 | Cinematography Skill | 景別、構圖、鏡位、運鏡、光線、鏡頭連續性 |
| 美術道具 | Art & Props Skill | 場景、服裝、道具、B-roll、UI、圖卡、素材清單 |
| 表演聲音 | Performance & Voice Skill | 表情、動作、語速、停頓、重音、情緒、聲線、口型要求 |
| 剪接後製 | Editor Skill | 剪輯點、節奏、轉場、動態字、SFX、BGM、特效 |
| 平台包裝 | Packaging Skill | 首幀、標題、封面、字幕安全區、平台版本、CTA |
| 監製QC | QC Supervisor Skill | 評分、硬失敗、退件、責任歸屬、發布閘門 |
| 數據分析 | Analytics Skill | 3秒留存、完播、互動、點擊、下一支學習建議 |

## 造型規則
每個職位有職業辨識度，但不得制服化成同一張臉：
- 導演：俐落片場造型，可見導演監看/耳機等工作元素，氣場明確。
- 攝影：機動、專業、適合片場操作的造型；鏡頭/燈光工作語彙清楚。
- 美術道具：有設計感與材質/色彩辨識，工作台或素材環境可成為角色場景。
- 編劇/企劃：創意工作者質感，不使用廉價辦公室模板。
- 剪接：後製工作室語彙，螢幕光與控制台可用但不遮臉。
- 表演聲音：乾淨錄音/表演指導環境，重視嘴型與表情可讀性。
- QC監製：成熟、精準、具有最終決策者辨識度。
- 數據分析：資訊視覺與數據牆語彙，但避免滿畫面假數字。

## 每位員工資料欄位
employeeId / displayName / primaryRole / primarySkill / secondarySkills / characterBible / visualBible / wardrobeLooks / voiceProfile / mannerisms / authorizedAssets / upstream / downstream / kpi / prohibitedActions / version。

## 下一步盤點規則
對現有員工逐一做：保留角色 → 評估強項 → 指派新職位 → 定主 Skill → 設計專屬造型 → 綁定素材 → 測試身份一致性。若兩人競爭同一職位，以能力與辨識度選主責，另一位轉入仍缺人的職位。
